INTRODUCTION                                                *nox-introduction*

nox.nvim provides syntax highlighting and language support for the Nox
programming language in Neovim.

==============================================================================
INSTALLATION                                                *nox-installation*

Using lazy.nvim:
>lua
    {
      "yourusername/nox.nvim",
      ft = "nox",
      config = function()
        require("nox").setup({})
      end,
    }
<

==============================================================================
CONFIGURATION                                              *nox-configuration*

Setup function accepts these options:
>lua
    require('nox').setup({
      debug = false,
      highlights = {
        NoxKeyword = { fg = "#ff0080", bold = true },
        -- ... more highlights
      },
      features = {
        auto_highlight = true,
      }
    })
<

==============================================================================
COMMANDS                                                        *nox-commands*

:NoxHighlight                                                  *:NoxHighlight*
    Force syntax highlighting on current buffer

:NoxRefresh                                                      *:NoxRefresh*
    Refresh highlighting for all Nox buffers

:NoxDebug                                                          *:NoxDebug*
    Toggle debug mode

:NoxStatus                                                        *:NoxStatus*
    Show status information

:NoxTest                                                            *:NoxTest*
    Create a test buffer with sample Nox code
